# Baseline data

`shot_baseline.csv` and `putt_baseline.csv` are from Evan Callaghan's Kaggle
dataset, [PGA Tour Strokes Gained Baseline
Values](https://www.kaggle.com/datasets/evancallaghan/pga-tour-strokes-gained-baseline-values),
version 1, published June 23, 2023.

The dataset description says its source values were aggregated from Mark
Broadie's *Every Shot Counts* (2014). Missing distances were completed by the
dataset author using cubic-spline interpolation from 10-600 yards and naive
short-distance extrapolation from 3-9 yards. Values are rounded to two decimal
places and described by the author as approximate.

Kaggle reports the license as **Other (specified in description)**. The dataset
description does not provide an additional standard license identifier. Keep
this provenance with the files and review reuse rights before commercial use.
